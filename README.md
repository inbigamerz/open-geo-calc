# Open Geo Calc 🌍📐

`open-geo-calc` is an open-source engineering toolkit designed to handle standard geotechnical and fluid mechanics computations programmatically. 

## Features
* **Darcy's Law Seepage Modeling**: Quickly compute flow and velocity parameters through saturated soils.
* **Manning's Open Channel Flow**: Evaluate channel velocities for drainage and hydraulic designs.
* **Lightweight & Modular**: Written in pure Python with zero heavy third-party dependencies.
